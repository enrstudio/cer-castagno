# Sito

Qui nascerà il sito statico di Seccheto 1.0, generato dal motore e
pubblicato con GitHub Pages sul dominio del progetto. HTML, CSS e
JavaScript senza framework né compilazione; mappa con Leaflet.

Sezioni previste:

- **Capire**: i concetti su tre livelli (in breve, come funziona, per approfondire)
- **Mappa**: case, superfici e potenziale solare
- **Le case**: una scheda per famiglia, con pseudonimo, anche in versione stampabile
- **Scenari**: confronto fra le ipotesi di gruppo

Le pagine di prova già fatte (questionario e guida ai conti) verranno
portate qui.
